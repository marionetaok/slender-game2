# Slender — The Eight Pages (versión corregida)

## Subir a GitHub Pages

1. Descomprime este ZIP.
2. Entra en tu repositorio de GitHub.
3. Sustituye `index.html`, `style.css`, `game.js` y `README.md` por los de esta carpeta.
4. Comprueba que `index.html` está directamente en la raíz del repositorio.
5. Ve a **Settings → Pages**.
6. En **Build and deployment**, selecciona:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
7. Guarda.
8. Espera aproximadamente 1–2 minutos y abre tu URL de GitHub Pages.

## Controles

- WASD o flechas: moverse
- Ratón: mirar
- F: encender/apagar linterna
- Shift: correr
- ESC: liberar el ratón
- Botón ⛶: pantalla completa

Al entrar en Google Sites, haz clic dentro del juego para activar el ratón.

El juego utiliza Three.js desde jsDelivr, por lo que necesita conexión a Internet.
